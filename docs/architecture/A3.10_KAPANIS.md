## 2. Yapılan tek fonksiyonel değişiklik

`sim/world.py` — `Vehicle`'a **opsiyonel hız profili**. Fonksiyonel kısmı
**4 satır**:

```diff
-                 turn_rate=0.0, wobble=0.0, name=""):
+                 turn_rate=0.0, wobble=0.0, name="", profil=None):
+        self.profil = profil
-        self.x += math.cos(hh) * self.speed * dt
-        self.y += math.sin(hh) * self.speed * dt
+        hiz = self.speed if self.profil is None else float(self.profil(self.t))
+        self.x += math.cos(hh) * hiz * dt
+        self.y += math.sin(hh) * hiz * dt
```

`profil=None` iken `hiz is self.speed` → mevcut yedi senaryoda **aritmetik
birebir**. Gazebo'daki kanıtlanmış `gazebo/senaryolar.py:Arac(profil=...)`
kalıbının sim karşılığıdır. `self.t` konvansiyonu `wobble` ile aynıdır
(artırımdan sonra okunur → k. karede `t = (k+1)·dt`).

## 5. Kayıt / replay

`veri/sim_kayit.py` (154 satır, yeni). Gazebo kayıt sisteminin **kopyası
değildir**: sim zaten deterministik olduğu için poz akışı, senkron denetimi,
RTF ve dünya üretimi **yoktur**.

```
data/sim/<ad>/meta.json            senaryo künyesi + hız profili + olaylar + seed
data/sim/<ad>/gt.csv               kare, t, GT(x,y,w,h), görünürlük, hedef konumu, hedef hızı
data/sim/<ad>/kareler/000000.png   kayıpsız kareler (.gitignore'da; 147 MB/senaryo)
```

* Yazıcı: `kaydet(senaryo, kok="data/sim")` — döngü sırası `calistir.kos()` ve
  `SimKaynak.oku()` ile **birebir aynı** (kamera → step → render).
* Okuyucu: `SimKayitKaynak(senaryo=...)` — `Kaynak` alt sınıfı, `Kare` üretir.
* `kaynak.py`, `main.py`, `calistir.py`, `SimKaynak` **değiştirilmedi**.
